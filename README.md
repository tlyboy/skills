# skills

🛠️ tlyboy's skills

## Install

```bash
npx skills add tlyboy/skills
```

## Usage

| Skill   | Description                                         |
| ------- | --------------------------------------------------- |
| starter | Create a new project from a tlyboy starter template |
| compose | Start common services from Docker Compose templates |
